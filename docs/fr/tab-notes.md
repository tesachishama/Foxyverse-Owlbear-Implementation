# Onglet Notes

[English (EN)](../tab-notes.md)

**Notes libres** par personnage, stockées sur la feuille (champ `notes` dans Supabase).

## Affichage vs édition

- Avec la permission **édition** : le **crayon** bascule le **mode édition**.
- **Mode affichage** — rendu HTML enrichi : mise en forme issue de la barre d’outils, et mêmes **boutons de jet inline** que le chat (`[type formule]`). Les boutons sont cliquables et postent les jets dans le chat.
- **Mode édition** — HTML / balises dans une zone de texte ; barre d’outils pour insérer du gras, italique, souligné, séparateur, titres H1–H3. Repassez en affichage pour prévisualiser.

## Défilement

Zone défilante avec flèches et curseur (comme le Chat).

## Qui peut modifier

En lecture seule, pas de crayon : affichage uniquement.
